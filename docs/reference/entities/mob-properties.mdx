Properties that can be set on mobs spawned by [Spawners](/docs/modules/mechanics/spawners).

## General Properties

| Attribute | Description | Value |
|---|---|---|
| `custom-name` | The mob's name. | <span className="badge badge--primary">String</span> |
| `custom-name-visible` | Always show the mob's name above it. | <span className="badge badge--primary">true/false</span> |
| `health` | The mob's health. | <span className="badge badge--primary">Decimal</span> |
| `max-health` | The mob's maximum health. | <span className="badge badge--primary">Decimal</span> |
| `fire-ticks` | How long the mob is on fire for, in ticks. | <span className="badge badge--primary">Number</span> |
| `can-pickup-items` | Toggle if the mob can pick up items. | <span className="badge badge--primary">true/false</span> |
| `remove-when-far-away` | Toggle if the mob despawns when no players are nearby. | <span className="badge badge--primary">true/false</span> |
| `arrows-stuck` | The number of arrows stuck in the mob. | <span className="badge badge--primary">Number</span> |
| `maximum-air` | The mob's maximum air, in ticks. | <span className="badge badge--primary">Number</span> |
| `remaining-air` | The mob's remaining air, in ticks. | <span className="badge badge--primary">Number</span> |
| `maximum-no-damage-ticks` | How long the mob is invulnerable for after taking damage, in ticks. | <span className="badge badge--primary">Number</span> |
| `no-damage-ticks` | How long the mob is invulnerable for after spawning, in ticks. | <span className="badge badge--primary">Number</span> |

## Modern Properties

These apply to all mobs. Not available in 1.8.

| Attribute | Description | Value |
|---|---|---|
| `silent` | Prevent the mob from making sounds. | <span className="badge badge--primary">true/false</span> |
| `glowing` | Give the mob a glowing outline. | <span className="badge badge--primary">true/false</span> |
| `invulnerable` | Prevent the mob from taking damage. | <span className="badge badge--primary">true/false</span> |
| `invisible` | Make the mob invisible. | <span className="badge badge--primary">true/false</span> |
| `persistent` | Prevent the mob from despawning. | <span className="badge badge--primary">true/false</span> |
| `gravity` | Toggle if the mob is affected by gravity. | <span className="badge badge--primary">true/false</span> |
| `no-physics` | Let the mob move through blocks. | <span className="badge badge--primary">true/false</span> |
| `collidable` | Toggle if the mob can be pushed by other entities. | <span className="badge badge--primary">true/false</span> |
| `ai` | Toggle if the mob moves and acts on its own. | <span className="badge badge--primary">true/false</span> |
| `aware` | Toggle if the mob reacts to its surroundings. | <span className="badge badge--primary">true/false</span> |
| `aggressive` | Put the mob in its aggressive pose. | <span className="badge badge--primary">true/false</span> |
| `left-handed` | Make the mob left-handed. | <span className="badge badge--primary">true/false</span> |
| `gliding` | Make the mob glide. | <span className="badge badge--primary">true/false</span> |
| `swimming` | Make the mob swim. | <span className="badge badge--primary">true/false</span> |
| `freeze-ticks` | How long the mob has been in powder snow, in ticks. | <span className="badge badge--primary">Number</span> |
| `portal-cooldown` | How long until the mob can use a portal, in ticks. | <span className="badge badge--primary">Number</span> |
| `no-action-ticks` | How long the mob has been idle, in ticks. | <span className="badge badge--primary">Number</span> |
